# 模拟盘板块设计方案

## 1. 产品定位

模拟盘是「策略实验场」而不是另一个实盘交易终端。它让用户用虚拟资金完成三件事：

1. 自己模拟买卖，验证主观判断。
2. 同时运行多个 Agent，每个 Agent 使用独立账户和策略。
3. 在统一大盘中比较个人与所有 Agent 的收益、回撤和稳定性。

## 2. 信息架构

### 一级：组合总览

- 组合总资产与近阶段收益
- 7D / 30D / 90D / ALL 多账户收益率对比曲线
- 所有账户统一以区间起点归零，避免不同初始资金影响横向比较
- 图例支持单独显示或隐藏账户曲线
- 今日收益、最大回撤、运行账户、组合胜率

### 二级：策略账户

- 「我的账户」固定作为自主模拟交易账户
- 每个 Agent 对应一个独立模拟账户
- 卡片只展示净值、累计收益、持仓数、胜率和运行状态
- 点击卡片切换下方持仓焦点

### 三级：操作与下钻

- 「模拟交易」通过右侧抽屉完成，避免交易表单常驻造成压迫
- 「添加 Agent」通过轻量弹窗创建账户
- 点击任一策略账户后，在同一区域切换查看持仓、决策记录和模拟交易记录
- 决策记录展示动作、标的、结论、置信度和执行结果，点击单条后再展开决策依据
- 模拟交易记录按实际成交时间展示动作、价格、数量和盈亏，并与对应决策关联
- Agent 模拟账户支持暂停、继续和删除；自主账户不可删除
- 删除仅移除模拟账户及其模拟数据，不删除「Agent 交易」中的原始 Agent
- 最近动态只展示当前最需要判断的信息

## 3. 核心数据模型

- `PaperPortfolio`：用户模拟盘的总组合，聚合所有账户净值
- `PaperAccount`：账户主体，类型为 `human` 或 `agent`
- `PaperOrder`：模拟委托，支持市价、限价、买入、卖出
- `PaperPosition`：账户级持仓、成本、浮动盈亏
- `EquitySnapshot`：账户与组合的时序净值快照
- `AgentBinding`：Agent、模型、策略版本与模拟账户的绑定关系
- `PaperDecision`：Agent 每轮决策快照，保存动作、理由、行情快照、置信度与执行状态
- `PaperTrade`：模拟撮合后的真实成交记录，通过 `decisionId` 回溯来源决策

所有账户应共享同一套行情时间基准、手续费和滑点规则，确保横向对比公平。

## 4. 关键流程

### 自主交易

进入模拟盘 → 默认选中「我的账户」→ 点击模拟交易 → 选择标的与金额 → 确认 → 更新持仓、动态与组合收益。

### Agent 交易

添加 Agent → 从「Agent 交易」中选择已创建的 Agent → 设置模拟初始资金 → 启动 → Agent 独立决策与下单 → 交易事件进入动态流 → 收益汇总至大盘。模拟盘只绑定 Agent，不在此处重复创建或编辑 Agent。

### Agent 生命周期管理

- 暂停：停止产生新的模拟决策和委托，保留账户、持仓与历史数据。
- 继续：从暂停状态恢复 Agent 模拟运行。
- 删除模拟账户：删除该账户在模拟盘中的资金、持仓、决策与成交数据，同时解除绑定；原 Agent 保留在「Agent 交易」中，后续可再次添加。

### 收益比较

查看组合大盘 → 通过账户卡片快速扫描 → 选中某账户 → 查看该账户持仓 → 后续可下钻到完整交易日志和决策解释。

### Agent 决策与模拟成交追溯

选中 Agent 账户 → 切换到「决策记录」查看每轮分析摘要 → 展开单条查看决策依据、参考价格、置信度和执行结果 → 切换到「模拟交易」核对实际成交。决策与成交需要通过 `decisionId` 关联，允许出现“已决策但未成交”和“风控自动成交”两类情况。

## 5. 视觉原则

- 高级简约：白色卡片、浅灰画布、深海军蓝主操作色。
- 单一视觉主角：首屏只保留一个多账户收益率对比图表。
- 低信息密度：摘要优先，明细按需展开。
- 克制使用红绿：只表达盈亏，不作为大面积装饰色。
- 所有数字使用等宽数字特性，增强金融信息的可扫读性。

## 6. 已接入的后端能力

- `GET /v1/paper-trading/dashboard`：组合摘要、账户列表和统一起点收益曲线
- `POST /v1/paper-trading/accounts`：从当前用户已有 Agent 创建独立模拟账户
- `POST /v1/paper-trading/accounts/{id}/pause|resume`：暂停或继续 Agent 模拟账户
- `DELETE /v1/paper-trading/accounts/{id}`：删除模拟账户及其模拟数据，不影响原 Agent
- `GET /v1/paper-trading/accounts/{id}/positions|decisions|trades`：账户明细
- `POST /v1/paper-trading/accounts/{id}/trades`：按实时行情价格执行自主模拟买卖
- `POST /v1/paper-trading/accounts/{id}/decisions`：供 Agent 执行链写入决策审计

数据库迁移为 `migrations/017_create_paper_trading_tables.sql`。数据按 `user_id` 和 `account_id` 隔离；所有资金、持仓与成交均为虚拟资产。

设置 `ENABLE_PAPER_TRADING_SCHEDULER=true` 后，后端会按各 Agent 的策略周期运行模拟决策；该调度器只写模拟盘表，不调用交易所下单接口。轮询频率可通过 `PAPER_TRADING_POLL_SECONDS` 调整。

## 7. 后续开发建议

第一期完成账户、模拟委托、持仓、净值快照、Agent 账户绑定和组合聚合接口；第二期增加 Agent 决策解释、账户对比和排行榜；第三期加入策略复制、回放与一键转回测能力。
