# QuantTrader UI 设计风格指南

## 设计理念

QuantTrader 采用 **暗色科技风（Dark Tech）** 设计语言，灵感来自专业级交易终端与现代数据仪表盘，追求简约、专业、沉浸的视觉体验。

## 色彩体系

### 背景层级
| 层级 | 色值 | 用途 |
|------|------|------|
| Base | `#0B0E17` | 页面底色 |
| Primary | `#111827` | 卡片/面板 |
| Secondary | `#0F1320` | 输入框/次级背景 |
| Elevated | `#1A1F35` | 浮层/弹窗 |

### 主色调
- **主色（青蓝）**: `#38BDF8` — 链接、主按钮、活跃态
- **渐变主色**: `#38BDF8 → #818CF8`（按钮/强调装饰）

### 功能色
| 颜色 | 色值 | 用途 |
|------|------|------|
| 盈利绿 | `#22C55E` | 正收益、多头 |
| 亏损红 | `#EF4444` | 负收益、空头 |
| 警告黄 | `#F59E0B` | 告警、待处理 |
| 信息紫 | `#8B5CF6` | 标签、辅助 |

### 文字色
- 主文字: `#F1F5F9`
- 次文字: `#94A3B8`
- 弱化文字: `#64748B`
- 禁用文字: `#475569`

### 边框
- 默认: `rgba(148, 163, 184, 0.12)`
- 活跃: `rgba(56, 189, 248, 0.4)`

## 组件规范

### 卡片
- 背景: `rgba(17, 24, 39, 0.8)` + `backdrop-filter: blur(12px)`
- 圆角: 12px
- 边框: 1px solid 半透明白
- 悬浮: 增强阴影 + 边框高亮为青蓝色

### 按钮
- 主要按钮: 青蓝→紫渐变，悬浮发光
- 默认按钮: 深色背景 + 半透明边框

### 表格
- 表头: 深色半透明背景，大写字母间距
- 行悬浮: 青蓝色 4% 透明度
- 固定列: 深色实背景避免穿透

### 图表（ECharts）
- 背景透明，融入卡片
- 线条: 渐变色（青蓝→紫）
- 面积: 向下渐变至透明
- 柱状图: 正值绿色渐变，负值红色渐变
- tooltip: 深色背景，白色文字

## 字体
- 英文: Inter
- 中文: PingFang SC / Noto Sans SC
- 等宽: ui-monospace, monospace

## 布局
- 侧边栏: 深色渐变，菜单项圆角 + 活跃态左侧渐变条
- 顶栏: 毛玻璃效果（半透明 + backdrop-filter）
- 内容区: Base 底色，卡片之间 24px 间距

## 动效
- 快速过渡: 0.15s ease
- 常规过渡: 0.25s ease
- 页面切换: 淡入 + 微向上位移
- 卡片悬浮: translateY(-2px) + 发光阴影
